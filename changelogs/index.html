      Version 2.1.0 - May 12, 2026

      • New: Covenant system foundations are in place.
        • Multiplayer participation now rewards two new currencies: Jar Coins and Tarnished Severed Fingers.
        • Spend them at the Roundtable Hold jar shop or trade with White Mask Varré for multiplayer-focused items.
        • Example earn rates:
          • 1 Jar Coin for helping a host to beat a boss.
          • 2 Jar Coins for defeating an invader as a hunter.
          • 2 Severed Fingers for killing the hunter as an invader.
          • etc.
      • New: Free-aim deadzone can now be disabled via the “Manual Attack Aiming” setting.
        • If you don’t know what this is, watch Amirah’s video on the topic: https://www.youtube.com/watch?v=mh2_Xs4vBfs
        • Also enables proper free-aim for bows, greatbows, and crossbows.
      • New: Team colors are now displayed in arena team match mode.
      • Significantly improved overall game and mod performance.
      • Reworked item restoration: “O’Jar of Plenty” has been replaced with a better system that tracks items used during a match and restores them when you use “Regressive Grease”.
      • Duel mode in arena now automatically triggers “Wondrous Physick” use at the start of each match.
      • Ghosts have been fully removed from the arenas.
      • More multiplayer fog walls have been removed.
      • Fixed several bugs around boss defeats and persistent session connections:
        • Beating the boss and dying simultaneously no longer causes a softlock.
        • Progressing through the game no longer triggers desyncs.
        • etc.
      • Fixed incorrect bounding boxes in the arena.
      • Fixed performance issues in the “Grand Library” map.
      • Fixed a session cleanup bug that was allowing faster rejoins in invasions and arena matches.
      • Matchmaking level ranges now more closely mirror vanilla behavior.
      • Fixed a Colosseum matchmaking issue when matched with someone in you blocklist.
      • Fixed an invalid starting class error display in the stats tracker.
      • Steam SDR initialization has been overhauled to reduce desyncs and improve connection stability.
      • Hardened launcher auto-update security.
      • Added self-diagnostic checks for common launcher issues.

      Version 2.0.2 - January 13, 2026

      • Fixed Torrent desync and an issue where he had a role name.
      • Changed hunter selection to pick randomly from the server’s pool instead of always choosing the first available.
      • Added recent invasion history to reduce repeated invasions against the same hosts.
      • Fixed a race condition that caused some phantom types to ignore limits in certain situations.
      • Added 1v1 duel maps to the arena, vanilla maps will put you into DEN Maps according to this mapping:
        • Royal Coliseum -> Dueling Square
        • Limgrave Coliseum -> Crystal Lake
        • Caelid Coliseum -> Seaside Arena
      • Made custom 2v2 respawns work in Brawl mode as well.
      • Fixed issue preventing Rune Arc from being used in the arena.

      Version 2.0.1 - January 10, 2026

      • Added a feature that prevents phantoms from being sent back home after killing the boss in co-op sessions.
