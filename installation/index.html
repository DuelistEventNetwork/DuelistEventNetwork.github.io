      Installation and Updates

      The mod comes with an easy-to-use launcher that handles installation and updates for you.

      Only download the mod from this (bettermultiplayer.com) website to ensure you’re getting the legitimate version.
      We are not responsible for any issues arising from downloading the mod from unofficial sources.

      Mod Compatibility: Currently, this mod is not compatible with any other mods.
      Because of this, please make sure you are not using any mod loaders that always load mods (e.g. Elden Mod Loader). Using such mod loaders may cause crashes or other issues.

      If you encounter issues, try removing dinput8.dll from your game directory if you have it.

      Installation (Windows)

      1. Download the latest Better Multiplayer release from the button above.
      2. Extract the .zip somewhere on your PC. Do not extract it inside a OneDrive-synced folder.
      3. Run BetterMultiplayer.exe.
      4. Follow the launcher prompts to start the game.

      Installation (Linux)

      1. Follow the Windows installation steps 1-2.
      2. Add BetterMultiplayer.exe as a “Non-Steam Game” in your Steam library and make it use Proton.
      3. Launch the mod from your Steam library.

      Updates

      • No manual updating is required. The launcher will automatically update the mod on startup.

      Save Files

      The mod uses the .den save file extension. If you want to transfer your existing save files to the mod:

      1. Locate your existing save file by opening %APPDATA%/EldenRing/ in the File Explorer.
      2. Navigate to the folder with your steam ID (e.g. 71234567000000000).
      3. Copy your existing save file (e.g ER0000.sl2) and rename it to ER0000.den.

      Bug Reporting

      You can report bugs in the Our Discord server in the #mod-feedback channel.
